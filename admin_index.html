데이터 동기화 (Firebase Firestore)

Firebase 동기화

Firebase와 연결되어 있지 않습니다. 로컬 저장소만 사용됩니다.

⚠️ Firebase 설정 필요

이 기능을 사용하려면 Firebase Firestore가 활성화되어 있고, 보안 규칙이 올바르게 설정되어 있어야 합니다.

  • Firestore 규칙: `allow read, write: if request.auth != null;`
  • 또는 `allow read, write: if true;` (테스트용)
  • 사용자 계정은 `users` 컬렉션에 저장됩니다.
